KmerHosting account access is handled through the KmerHosting Dashboard at `dashboard.kmerhosting.com`. The public `/login` route redirects to the Dashboard login page.

<Frame caption="The login page supports the authentication methods enabled for the customer account.">
  ![The login page supports credentials and configured social providers.](/images/screenshots/login-page.png)
</Frame>

## Session behavior

If the Dashboard unexpectedly returns to login, test from a private browser window and remove stale KmerHosting site data before signing in again. Do not assume an old `console.kmerhosting.com` session or cookie is part of the current account flow.

## Password recovery

<Frame caption="Password recovery starts with the email address attached to the customer account.">
  ![Password recovery starts with the email address attached to the customer account.](/images/screenshots/forgot-password.png)
</Frame>

1. Open the password-recovery flow from `dashboard.kmerhosting.com/login`.
2. Enter the account email address.
3. Follow the recovery message.
4. Choose a new password that is not reused for DirectAdmin, VPS root, email, or API keys.

## Safe troubleshooting

- Verify the browser is not blocking cookies required by the Dashboard.
- Test in a private window to separate current behavior from stale cookies.
- Confirm the system clock is correct.
- Do not copy session cookies, one-time codes or passwords into scripts or support messages.
