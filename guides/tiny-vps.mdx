Tiny VPS provides a lightweight Linux container with root access for small applications, staging environments, automation tasks, and private services.

## Choose a plan

- **Tiny 512:** 1 vCPU, 512 MB RAM, 10 GB storage, 1 TB traffic, 1 snapshot.
- **Tiny 1G:** 1 vCPU, 1 GB RAM, 20 GB storage, 2 TB traffic, 1 snapshot.
- **Tiny 2G:** 1 vCPU, 2 GB RAM, 30 GB storage, 3 TB traffic, 2 snapshots.
- **Tiny 4G:** 2 vCPU, 4 GB RAM, 50 GB storage, 5 TB traffic, 3 snapshots.
- **Tiny 8G:** 4 vCPU, 8 GB RAM, 100 GB storage, 8 TB traffic, 5 snapshots.

Traffic and snapshot allowances are finite and plan-specific. Check the LXC service portal for the live order configuration.

## Connect to the server

After activation, retrieve the IP address, SSH username, and credentials from the customer console.

~~bash ssh root@SERVER\_IP ~~

## Initial security steps

Update the operating system after your first connection:

~~bash apt update apt upgrade -y ~~

Create a non-root administrator:

~~bash adduser deploy usermod -aG sudo deploy ~~

Configure an SSH key before disabling password authentication.

## Suitable workloads

Tiny VPS works well for:

- Node.js, Python, PHP, and Go applications
- Development and staging environments
- Small databases used for testing
- Background workers and cron jobs
- Monitoring and private administration tools
- Lightweight websites and APIs

## Deploy a Node.js application

Install Node.js, npm, Git, and Nginx:

~~bash apt install -y nodejs npm git nginx ~~

Clone the application:

~~bash mkdir -p /var/www/application git clone YOUR\_REPOSITORY\_URL /var/www/application cd /var/www/application ~~

Install dependencies and build:

~~bash npm install npm run build ~~

Install PM2 and start the application:

~~bash npm install --global pm2 pm2 start npm --name application -- start pm2 save ~~

Enable PM2 at server startup:

~~bash pm2 startup ~~

Run the command displayed by PM2, then execute:

~~bash pm2 save ~~

## When to consider KVM VPS

Consider KVM VPS when you specifically require full virtual-machine isolation or a workload that does not fit LXC container virtualization. KVM capacity may be **Out of stock**, so check the current service status before planning a migration.

Do not use KVM merely as a generic “upgrade” assumption: select the service according to isolation, resource and operating-system requirements.
