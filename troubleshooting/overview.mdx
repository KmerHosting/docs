## Start here

1. Check the [status page](https://status.kmerhosting.com) for a platform incident or maintenance.
2. Confirm that you are signed in to the account that owns the service.
3. Open the central service inventory, then the product portal for the affected service.
4. Record the time and timezone, service ID, operation, current state, expected result, and sanitized error.
5. For API failures, preserve the `request_id`, route, status, and idempotency key—but never the API secret.

If the issue remains, use [support](https://kmerhosting.com/support). Do not send passwords, private keys, API keys, temporary access URLs, full payment-card details, or one-time codes.
