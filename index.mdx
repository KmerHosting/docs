KmerHosting brings hosting, domains, professional email, VPS infrastructure, standalone products, and developer interfaces into one account. Use this documentation to move from setup to day-to-day operations without guessing which portal or API owns a workflow.

<CardGroup cols={3}>
  <Card title="One customer account" icon="user-round-check">
    Billing, renewals, service inventory, API keys, notifications, and central account settings live in the Customer Dashboard.
  </Card>

  <Card title="Purpose-built portals" icon="panels-top-left">
    Domains, Email Hosting, Shared Hosting, LXC, and other products keep specialized controls in their own service portals.
  </Card>

  <Card title="Developer-friendly" icon="braces">

  </Card>
</CardGroup>

## Quick start

### Choose your path

<CardGroup cols={2}>
  <Card title="For customers" icon="layout-dashboard" href="/quickstart">
    Create an account, add credit when needed, choose an available service, and open the correct product portal.
  </Card>

  <Card title="For developers" icon="terminal" href="/developer/overview">
    Create a scoped API key, choose an SDK or tool, make your first authenticated request, and keep request IDs for support.
  </Card>
</CardGroup>

### Start in three steps

<Steps>
  <Step title="Open the Customer Dashboard">
    Sign in at [dashboard.kmerhosting.com](https://dashboard.kmerhosting.com). The dashboard is authoritative for your account, billing, services, renewals, and API keys.
  </Step>

  <Step title="Choose the right service or interface">
    Use **All services and products → Availability** for currently orderable services. Developers can start with the [SDKs and tools](/developer/overview).
  </Step>

  <Step title="Manage the resource in its owning portal">
    Return to the Customer Dashboard for central account work, or open the dedicated service portal for product-specific operations.
  </Step>
</Steps>
