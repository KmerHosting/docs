## Build and manage on KmerHosting

KmerHosting currently exposes four managed product areas through its public developer platform: domains and DNS, Email Hosting, Shared Hosting, and LXC VPS. Use the customer console to manage your account and services; use an API key, SDK, CLI, or MCP connection for supported automation.

## What is intentionally not in the public API

The public API does not expose purchases, billing, provider credentials, account administration, destructive provider-side actions, or secrets. Use the customer console for workflows outside the documented API contract.
