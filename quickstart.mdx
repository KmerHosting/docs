## Start as a customer

1. Create or sign in to your [Customer Dashboard](https://dashboard.kmerhosting.com).
2. Add account credit through a payment option shown to your account.
3. Open the [live catalog](https://kmerhosting.com/pricing), choose an available product, and review the final plan, period, region, limits, support level, and renewal price.
4. Complete checkout only once, then follow the displayed order or provisioning status.
5. Open the service from the central inventory. KmerHosting sends you to the specialized Domain, Email, Shared Hosting, LXC, or KVM portal when needed.

See [account and billing](/console/account-and-billing) before enabling auto-renew or scheduling cancellation.

## Choose a developer interface

| Need | Use |
| --- | --- |
| Build a server-side integration | [REST API](/developer/rest-api) or [SDK](/developer/sdk) |
| Run an operational command | [CLI](/developer/cli) |
| Let a compatible AI client manage supported resources | [MCP](/developer/mcp) |
| Purchase, pay for, or administer an account | Customer Dashboard or product portal |

## 1. Create a scoped API key

In the **main KmerHosting Dashboard**, open **Developer tools → API keys**, select only the scopes your integration needs, choose a short expiration, add trusted IPv4 addresses when required, and copy the secret once. Store it in a server-side secret manager.

```bash
export KMERHOSTING_API_KEY='kh_live_...'
```

Never put this value in browser code, a mobile app, a repository, screenshots, or logs.

## 2. Verify access

```bash
curl --fail-with-body https://api.kmerhosting.com/v1/account \
  -H "Authorization: Bearer $KMERHOSTING_API_KEY"
```

Every successful API response contains `data` and `request_id`. Keep the request ID when contacting support.

## 3. List services

```bash
curl --fail-with-body https://api.kmerhosting.com/v1/services \
  -H "Authorization: Bearer $KMERHOSTING_API_KEY"
```

Continue with [product documentation](/products/overview) for service-specific behavior, or use the [OpenAPI reference](/api-reference) for exact requests and responses.
