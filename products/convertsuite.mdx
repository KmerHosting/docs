ConvertSuite is KmerHosting's browser-based document, image, PDF, and media toolkit. Open [convertsuite.pro](https://convertsuite.pro) to use the web tools or review the available plan options.

## Plans and operations

ConvertSuite uses the shared KmerHosting account and credit system. It does not create a separate product wallet or account.

- **Free:** 5 operations per day, with no sign-in required for web use.
- **Pro:** $5/month or $30/year, 100 included operations per day, and REST API access.
- **Business:** $15/month or $90/year, 1,000,000 included operations per day, and REST API access.

Free customers can buy 10 extra operations for $0.25 after using the daily included allowance. Pro and Business customers can buy extra operations in packs of 10 for $0.05. Daily included operations are consumed first, followed by purchased operations. Purchased operations persist across days and are tracked separately from the daily included quota.

## Account, credit, and lifecycle

Sign in through the shared KmerHosting identity to activate a paid plan, manage renewal, cancel at the end of the current period, or resume automatic renewal. Subscription charges and extra-operation purchases use the central KmerHosting credit balance and appear in the central ledger and billing documents.

If the balance is insufficient, nothing is activated or purchased. Use the **Add KmerHosting credit** flow in the ConvertSuite account panel, which opens the standard KmerHosting CamerPay top-up flow, then retry the pending action.

KmerHosting sends lifecycle notifications for activation, plan changes, renewal reminders, failed renewals, cancellation, resumed renewal, expiry, and purchased operation packs through the existing account email infrastructure.

## API access

REST API access is included with Pro and Business plans. The processing API is available at `https://api.convertsuite.pro` and uses the ConvertSuite session returned by KmerHosting SSO.

The browser-facing contract is:

- `GET /health` and `GET /v1/tools` for service health and the supported tool catalog.
- `POST /v1/prepare-upload` with `{ tool, idempotencyKey, files, options }` to reserve one operation per input and receive one-time signed upload URLs.
- `POST /v1/jobs/{jobId}/start` after all signed uploads complete.
- `GET /v1/jobs/{jobId}` to poll status and receive short-lived artifact download URLs.
- `POST /v1/jobs/{jobId}/cancel` to cancel an upload that has not started.

Server-to-server callers send the same KmerHosting ConvertSuite session as `Authorization: Bearer <session>` and add `x-convertsuite-api: 1`; that path requires an active Pro or Business entitlement. Browser web requests use the `x-convertsuite-session` header and remain available on Free.

Inputs are private, limited to 50 MB per file, and retained for up to 24 hours. Daily included operations are consumed before persistent purchased operations, using the same atomic quota functions as the web interface.
