## Catalog and billing

The live Shared Hosting catalog supplies the available plans, control-panel type, limits, features, price, and availability. It supports cPanel and DirectAdmin offerings. The current product workflow supports one-, three-, six-, and twelve-month periods and unmanaged or managed support levels where offered.

The final price, availability, selected panel, and included features must always be read from the live catalog or the purchased service record. Do not rely on a copied price table.

## Choose and purchase a plan

Shared Hosting includes cPanel and DirectAdmin plans plus Standard, PHP, WordPress, Node.js, Python, and Laravel families where the live catalog offers them. Runtime families and features differ by control panel; do not assume that a feature present on one plan exists on another.

Free Hosting is documented separately in [Free Hosting](/products/free-hosting). It is part of Shared Hosting, but its zero-price lifecycle and inactivity policy are different from paid plans.

At checkout, confirm the primary domain, DNS readiness, control panel, plan family, managed or unmanaged support level, billing period, limits, final price, and stock. You can use an offered temporary subdomain when the permanent domain is not ready. A move between cPanel and DirectAdmin or between plan families can require a support-assisted migration rather than an in-place upgrade.

## Manage an active service

The Shared Hosting portal shows the primary domain, server, DNS and SSL guidance, credentials, resource statistics, panel type, and temporary control-panel or File Manager access. It also supports auto-renew, manual renewal, prorated upgrade quotes, eligible upgrades, scheduled cancellation, and cancellation revocation.

- Use cPanel controls for cPanel services and DirectAdmin controls for DirectAdmin services.
- Temporary access links are secrets; open them only on a trusted device and let them expire.
- Resource statistics can be delayed or provider-specific. Compare sustained usage with plan limits before upgrading.
- Back up site files and databases before application, DNS, migration, or major runtime changes.
- Downgrades and cross-family/control-panel moves require support review because limits and data layouts can change.

## Supported API operations

| Operation | Scope | Notes |
| --- | --- | --- |
| List owned services | `hosting:read` | Returns supported service inventory fields. |
| Retrieve statistics | `hosting:read` | Provider-neutral: DirectAdmin or cPanel is selected from the owned service. |
| Create temporary panel access | `hosting:panel:access` | `target` is `panel` or `filemanager`; default is `panel`. |

```bash
curl --fail-with-body -X POST \
  "https://api.kmerhosting.com/v1/hosting/services/SERVICE_ID/panel-access" \
  -H "Authorization: Bearer $KMERHOSTING_API_KEY" \
  -H "Idempotency-Key: panel-access-20260831" \
  -H "Content-Type: application/json" \
  -d '{"target":"panel"}'
```

The returned panel link is temporary. Treat it as sensitive and do not send it to untrusted recipients.
