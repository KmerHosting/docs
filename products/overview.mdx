## Lifecycle

The customer console is the authoritative interface for ordering and billing. After an order is accepted, the service inventory can show pending, active, suspended, cancelled, or renewal-related states according to the product workflow. API listing endpoints return only services belonging to the authenticated account.

Use the central service inventory when you need a cross-product view. Use the product endpoint when you need a specialized operation such as DNS management, panel access, LXC inspection, or KVM snapshot management.

## Pricing

Prices, terms, plan limits, and availability come from the live product catalog and from the service record after purchase. They are intentionally not duplicated here. A stored service can expose its plan name, renewal price and currency, billing term, renewal date, and auto-renewal state through the console or applicable API response.

## Capability by interface

| Product | Customer portal | Public developer platform |
| --- | --- | --- |
| Domains | Ordering, transfers, contacts, DNS, security, renewals, documents | Owned inventory, DNS, nameservers, auto-renew |
| Email Hosting | Ordering, DNS verification, mailboxes, webmail, billing | List services, provision, synchronize DNS |
| Shared Hosting | Ordering, service details, panel access, renewal, upgrade, cancellation | List, provider-neutral statistics, temporary panel/File Manager access |
| LXC VPS | Full customer lifecycle, power, metrics, snapshots, terminal, web domains, billing | List and inspect owned instances |
| KVM VPS | Existing-service power, credentials, snapshots, renewal, cancellation | Inventory, power, auto-renew, snapshot create/update/delete |
| wFileManager | Self-hosted application | No KmerHosting account API |

Portal-only does not mean unsupported. It means the workflow needs customer-session context, an interactive confirmation, or a public API contract that has not been released.
