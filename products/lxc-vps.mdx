## Supported operations

The public API lists and inspects owned LXC instances. Lifecycle actions, billing changes, terminal access, credentials, and snapshots remain console-only while their customer-safe API contracts are completed.

| Operation | Scope |
| --- | --- |
| List and inspect | `lxc:read` |

```bash
curl --fail-with-body \
  "https://api.kmerhosting.com/v1/lxc/instances" \
  -H "Authorization: Bearer $KMERHOSTING_API_KEY"
```

Purchases, lifecycle actions, snapshots, reinstalling an operating system, root-password handling, terminal access, and unmanaged provider controls are not public API operations.
