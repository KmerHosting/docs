---
title: "Customer Dashboard and product portals"
description: "Know where to manage KmerHosting account, billing, service, and product-specific workflows."
---

The Customer Dashboard is the source of truth for central account work. It provides the overview, service inventory, live product links, developer tools, API keys, notifications, account credit, invoices and receipts, renewals, account settings, and account analytics.

Product portals hold specialized workflows:

| Portal | Typical work |
| --- | --- |
| Domains | Search, registration, transfer, contacts, DNS, security, renewal, documents |
| Email Hosting | Domain setup, DNS verification, mailboxes, webmail, limits, billing |
| Shared Hosting | Purchase, credentials, cPanel/DirectAdmin access, usage, renewals, upgrades |
| LXC | Deploy, instance controls, metrics, snapshots, terminal, web domains, billing |
| KVM | Existing instance controls, password reset, snapshots, renewals, cancellation |

Opening a product portal does not create a second KmerHosting identity. Use the same customer account and follow the ownership links shown in the dashboard.

Use the public API, SDK, CLI, or MCP server only for operations documented in this site. They intentionally cannot expose secret-bearing, provider-administration, or broader account-management workflows.
