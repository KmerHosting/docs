## Common rules

All developer interfaces operate on resources owned by the authenticated KmerHosting account. Scopes grant access by resource family; a successful response is not permission to perform undocumented or provider-side operations.

Use idempotency for every write. SDKs and the CLI generate a key when you do not supply one, but retries of the same logical request should reuse a stable key. Keep `request_id` values from errors and unexpected results.
