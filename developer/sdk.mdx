## Packages

| Language | Package | Install |
| --- | --- | --- |
| TypeScript | `@kmerhosting/sdk` | `npm install @kmerhosting/sdk` |
| Python | `kmerhosting-sdk` | `pip install kmerhosting-sdk` |
| PHP | `kmerhosting/sdk` | `composer require kmerhosting/sdk` |
| Java 17+ | `com.kmerhosting:kmerhosting-sdk` | Maven Central dependency |

All clients read `KMERHOSTING_API_KEY` by default and expose the same resource families: `account`, `services`, `domains`, `email`, `hosting`, `lxc`, and `kvm`. Write methods generate idempotency keys if none is supplied. The former `vps` resource is retired.

## TypeScript

```ts
import { KmerHostingClient } from "@kmerhosting/sdk";

const client = new KmerHostingClient({ apiKey: process.env.KMERHOSTING_API_KEY });
const services = await client.services.list();
```

## Python

```python
from kmerhosting import KmerHostingClient

client = KmerHostingClient()
services = client.services.list()
```

## PHP

```php
use KmerHosting\Client;

$client = new Client();
$services = $client->services()->all();
```

## Java

```xml
<dependency>
  <groupId>com.kmerhosting</groupId>
  <artifactId>kmerhosting-sdk</artifactId>
  <version>0.2.0</version>
</dependency>
```

```java
var client = new KmerHostingClient();
var services = client.services().list();
```

Java returns Jackson `JsonNode` API envelopes. See each package README and the [API reference](/api-reference) for method-to-endpoint mapping.
