## Install and authenticate

```bash
export KMERHOSTING_API_KEY='kh_live_...'
```

Use the TypeScript, Python, PHP, or Java [SDK](/developer/sdks) for scripts and automation. Use the hosted [MCP server](/developer/mcp) for compatible AI clients. There is no separately published KmerHosting CLI package at this time.

## Safe automation

Set the API key only in a protected server environment. Every write must have a unique idempotency key. KVM power and snapshot scopes require a matching IPv4 allowlist on the key; do not automate those actions from an untrusted or dynamic address.
