## Install and authenticate

Install the CLI, then provide a short-lived, narrowly scoped API key through the environment. The GitHub source install works immediately while the npm organization publication is being completed:

```bash
bun add --global github:KmerHosting/cli
export KMERHOSTING_API_KEY='kh_live_...'
kmerhosting account get
```

On Windows PowerShell, Bun may print a `PATH` warning after a global install. Add its global bin directory to the current session, then run the command:

```powershell
$env:Path = "$HOME\.bun\bin;$env:Path"
$env:KMERHOSTING_API_KEY = "kh_live_..."
kmerhosting account get
```

To persist the path for future PowerShell windows, add `C:\Users\<you>\.bun\bin` to your user **Path** environment variable and open a new terminal.

The npm and Bun registry commands use the same public npm registry and will be available after `@kmerhosting/cli` is published there:

```bash
npm install --global @kmerhosting/cli@latest
bun add --global @kmerhosting/cli@latest
```

If npm returns `E404`, use the GitHub command above; it means the npm publication or organization permissions are not complete yet, not that the CLI command name is different.

Use `--json` for machine-readable output and `--base-url` only when KmerHosting support has given you a non-production endpoint.

## Resource commands

```bash
kmerhosting services list
kmerhosting domains list
kmerhosting hosting services
kmerhosting lxc list
kmerhosting kvm view INSTANCE_ID
kmerhosting kvm action INSTANCE_ID restart
```

LXC and KVM are deliberately separate. `lxc` exposes the public read operations currently supported for LXC inventory. `kvm` exposes inventory, power, auto-renew, and snapshot operations for owned KVM services. The retired `vps` resource returns a migration message instead of guessing the product.

Run `kmerhosting --help` for the complete command list. For writes, `--idempotency-key VALUE` lets a retry reuse the same logical request. Destructive operations require `--yes`.

## Safe automation

Set the API key only in a protected server environment. Every write must have a unique idempotency key. KVM power and snapshot scopes require a matching IPv4 allowlist on the key; do not automate those actions from an untrusted or dynamic address. See [API keys and scopes](/developer/api-keys) before using the CLI in CI.
