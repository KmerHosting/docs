KmerHosting LXC VPS Hosting provides an isolated Linux container with root and SSH access for workloads that need more control than Shared Hosting without requiring a full KVM virtual machine.

## Best suited for

- Small APIs and backend services
- Development and staging environments
- Cron jobs and automation workers
- Private tools and internal dashboards
- Lightweight websites and applications
- Linux experiments and learning environments

## Included and limited by plan

- LXC virtualization
- Linux operating system
- Full SSH and root access
- AMD EPYC compute
- DDR4 memory
- NVMe-backed SSD storage
- Traffic quota shown for the selected plan
- Snapshot quota shown for the selected plan

LXC traffic is **not unlimited**. The applicable traffic quota is the amount shown for the selected plan and service record.

A free domain is **not** included with LXC VPS unless a specific order or promotion explicitly states otherwise.

## LXC compared with KVM VPS

LXC VPS is the currently available lightweight server line. KVM VPS provides full virtual-machine isolation when external infrastructure capacity is available.

Choose KVM VPS when you specifically require full VM isolation or a workload that does not fit container virtualization. KVM VPS may be marked **Out of stock** when external capacity is unavailable; do not treat its documentation as a statement that it can always be ordered.
