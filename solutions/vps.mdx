KVM VPS Hosting is the KmerHosting virtual-machine line for workloads that need full VM isolation and greater operating-system control than Shared Hosting or LXC containers.

<Warning>
  KVM VPS availability depends on external infrastructure capacity. When the service is marked **Out of stock** on kmerhosting.com, this documentation describes the product model but does not mean a new KVM VPS can currently be ordered.
</Warning>

## Typical workloads

- Production web applications and APIs
- Docker and Docker Compose stacks
- Background workers and scheduled jobs
- Databases, caches, queues and private services
- Reverse proxies, monitoring and deployment automation
- Self-managed hosting panels when supported by the selected offer

## Access and responsibility

A KVM VPS can expose root or administrative credentials. The customer is responsible for operating-system updates, SSH security, firewall policy, application configuration, independent backups and secret management unless a managed agreement explicitly says otherwise.

## KVM compared with LXC VPS

LXC VPS uses lightweight Linux containers and is the currently available server line for compatible Linux workloads. KVM VPS provides full virtual-machine isolation and depends on external capacity.

Do not infer current orderability from this guide. Check the canonical KVM service page for the current status before planning a deployment.
